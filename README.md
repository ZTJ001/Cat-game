# 厨房猫偷鱼干 🐱🐟

一个可以直接在浏览器里玩的 HTML5 小游戏：**小猫在厨房偷鱼干，躲开扫地机器人，还要提防会抢鱼、会狂暴的小老鼠**。

整个游戏就是 **一个 `dist/index.html` 文件**，不需要安装任何依赖、不需要联网、不需要后端或 API Key。

---

## 一、如何游玩（其他电脑本地部署）

### 方法 A：最简单——双击打开

1. 克隆仓库（或下载 ZIP 后解压）：

   ```bash
   git clone https://github.com/ZTJ001/Cat-game.git
   cd Cat-game
   ```

2. 用浏览器打开 `dist/index.html`（直接双击即可）。

3. 点击「开始游戏」就能玩。**无需任何安装、无需联网。**

### 方法 B：用本地服务器打开（可选）

如果想通过 `http://` 访问（例如手机同局域网测试），在仓库根目录执行任意一条：

```bash
# Python 3
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000/dist/
```

```bash
# Node.js（若已安装）
npx serve .
# 然后访问 http://localhost:3000/dist/
```

> 直接用 `file://` 双击打开是没问题的——游戏把所有 CSS/JS/音效都内联在单个 HTML 里，不加载任何外部资源。

## 三、玩法规则

### 基础
- **鱼干**：吃到计入进度，满 20 条获胜。
- **扫地机器人**：四处巡逻，撞到猫会扣 1 条命，猫短暂无敌并被击退；撞完机器人也会短暂眩晕。
- **逗猫棒**：随机出现、限时未拾取即消失；碰到后猫的速度 **×2 持续 10 秒**。

### 小老鼠（场上始终最多 1 只）
- **随机刷新**：开局随机 8~15 秒后出现；消失后随机 45~75 秒再来；位置也随机，并避开猫、机器人和鱼干。
- **普通阶段**：会自己躲猫、抢鱼干；每吃 1 条鱼干**变大 10% 并 +1 条命**。
- **被机器人撞**：普通阶段原地眩晕 3 秒。
- **狂暴阶段**：吃满 5 条鱼干后全屏闪过「⚠ 小心老鼠 ⚠」警报，进入 **6 秒狂暴**——主动追猫、撞猫扣 1 命（与机器人机制一致），期间不再吃鱼、猫也打不动它；每碰一次机器人自己 -1 命。
- **狂暴结束**：扣 2 条命、吃鱼进度归零、体型缩回基础，必须重新吃满 5 条才能再次狂暴。
- **猫攻击**：猫贴到普通阶段的老鼠可以撞掉它 1 条命；**亲手把老鼠打死可以给猫补 1 条命**（可超过初始上限）。狂暴阶段无法攻击。
- **老鼠消失**：命数归零后从画面消失，进入重生倒计时；只有「猫亲手打死」才会给猫补命，其它致死方式不补。

## 四、仓库结构

```
Cat-game/
├── dist/
│   └── index.html      ← 游戏本体（唯一运行必需文件，单文件全内联）
├── game.json           ← 游戏规则与元数据（供工具/测试读取）
├── layout-audit.cjs    ← 关卡连通性与软锁审计脚本
├── simulate.cjs        ← 自动试玩模拟脚本
├── test-feedback.cjs   ← 反馈层回归测试
├── test-boost.cjs      ← 逗猫棒增益回归测试
├── test-layout.cjs     ← 关卡脱身回归测试
├── test-mouse.cjs      ← 小老鼠机制回归测试
└── README.md           ← 本文档
```

只有 `dist/index.html` 是游玩必需的，其余是开发与回归测试用的脚本（**运行游戏不需要 Node.js**）。

---

## 五、开发者：运行回归测试（可选）

如需修改游戏后验证，安装 Node.js 后在项目根目录执行：

```bash
node layout-audit.cjs   # 关卡审计：无边界软锁
node test-layout.cjs    # 关卡脱身测试
node test-feedback.cjs  # 反馈层测试
node test-boost.cjs     # 逗猫棒测试
node test-mouse.cjs     # 小老鼠机制测试
node simulate.cjs       # 自动试玩模拟
```

这些测试用 Node 的 `vm` 模块模拟浏览器环境，不依赖真实浏览器。

## 六、技术说明

- 纯 HTML + CSS + 原生 JavaScript，Canvas 2D 渲染。
- 所有资源内联在单个 HTML 中：无图片、无字体、无音频文件；音效用 Web Audio API 实时合成。
- 无框架、无构建步骤、无后端、无需联网或 API Key。
- 关卡与机制经过无头回归测试覆盖（布局、反馈、增益、老鼠 AI、自动试玩）。
